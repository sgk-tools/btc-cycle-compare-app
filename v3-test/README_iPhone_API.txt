BTCサイクル比較 v3.2 cycle-definition + ON/OFF

目的
- 2010年7月の市場価格データ開始から現在まで、BTCの主要サイクルを同じ軸で比較する。
- サイクル定義を「主要ATH → 次の主要ATH」に統一する。
- 主要サイクル：2011、2013、2017、2021、現在。
- 2013年4月の中間ピークは独立サイクルにせず、2011→2013サイクル内に含める。
- 比較モード：ATH→現在 / ATH→底値 / 底値前後 / ATH→次ATH。

v3.2変更点
- 2013前半 / 2013後半の分割を廃止し「2013」に統合。
- グラフ凡例をON/OFFスイッチ化。
- 2011 / 2013 / 2017 / 2021 / 現在を個別に表示・非表示可能。
- 「全表示」ボタンを追加。
- ON/OFF状態はlocalStorageへ保存。
- ON/OFFはグラフ表示だけに反映し、比較表には全サイクルを残す。

データ
- 2010-07-18〜2017-08-16：CoinGecko由来の日次BTC/USD履歴（GitHub公開ミラー、jsDelivrフォールバック）。
- 2017-08-17以降：Binance Spot API BTCUSDT daily klines。
- APIキー不要。
- 取得データはlocalStorageに保存。v3.0の保存データも再利用可能。

UI / 動作
- PC / iPhone / Androidのレスポンシブ対応。
- 更新ボタン押下中は「取得中」と表示し二重押しを防止。
- PWA対応。ホーム画面追加可能。

GitHub Pages試験版更新
- GitHubリポジトリ直下へ、このZIP内の v3-test フォルダをアップロードする。
- 既存の /v3-test/ の4ファイルを上書きする。
- 試験URL：https://sgk-tools.github.io/btc-cycle-compare-app/v3-test/

注意
- Bitcoinネットワーク自体は2009年開始だが、市場価格比較は2010年7月以降を対象とする。
- 2017年8月付近でデータソースが切り替わるため、価格定義に小さな差があり得る。
- 現在サイクルの底値は未確定のため「暫定底」と表示。
- 2021サイクルの終点は、その時点で確認できる現行ATHを使用し、新ATH更新時は自動更新される。
- このアプリは位置確認用。売買判断ではない。
