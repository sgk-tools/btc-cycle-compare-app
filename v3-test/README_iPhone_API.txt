BTCサイクル比較 v3.4 intraday-low + bottom-stats + range-zoom + ON/OFF

目的
- 2010年7月の市場価格データ開始から現在まで、BTCの主要サイクルを同じ軸で比較する。
- サイクル定義を「主要ATH → 次の主要ATH」に統一する。
- 主要サイクル：2011、2013、2017、2021、現在。
- 2013年4月の中間ピークは独立サイクルにせず、2011→2013サイクル内に含める。
- 比較モード：ATH→現在 / ATH→底値 / 底値前後 / ATH→次ATH。

v3.3主機能
- 2013前半 / 2013後半の分割を廃止し「2013」に統合。
- グラフ凡例をON/OFFスイッチ化。
- 2011 / 2013 / 2017 / 2021 / 現在を個別に表示・非表示可能。
- 「全表示」ボタンを追加。
- ON/OFF状態はlocalStorageへ保存。
- ON/OFFはグラフ表示だけに反映し、比較表には全サイクルを残す。

データ
- 2010-07-18〜2017-08-16：CoinGecko由来の日次BTC/USD履歴（GitHub公開ミラー、jsDelivrフォールバック）。
- 2017-08-17以降：Binance Spot API BTCUSDT daily klines。
- APIキー不要。
- 取得データはlocalStorageに保存。v3.0の保存データも再利用可能。

UI / 動作
- PC / iPhone / Androidのレスポンシブ対応。
- 更新ボタン押下中は「取得中」と表示し二重押しを防止。
- PWA対応。ホーム画面追加可能。

GitHub Pages試験版更新
- GitHubリポジトリの /v3-test/ フォルダを開いてから、ZIP内 v3-test フォルダの中にある4ファイルのみをアップロードする。
- 既存の /v3-test/ の4ファイルを上書きする。
- 試験URL：https://sgk-tools.github.io/btc-cycle-compare-app/v3-test/

注意
- Bitcoinネットワーク自体は2009年開始だが、市場価格比較は2010年7月以降を対象とする。
- 2017年8月付近でデータソースが切り替わるため、価格定義に小さな差があり得る。
- 現在サイクルの底値は未確定のため「暫定底」と表示。
- 2021サイクルの終点は、その時点で確認できる現行ATHを使用し、新ATH更新時は自動更新される。
- このアプリは位置確認用。売買判断ではない。


[v3.2 変更点]
・ATH→現在 / ATH→底値：100日・200日・365日・500日・全期間
・底値前後：±100日・±200日・±365日・±500日
・ATH→次ATH：365日・500日・1000日・1500日・全期間
・1000日/1500日は長期サイクル確認用としてATH→次ATHだけに限定


[v3.3 変更点]
・グラフ直下に「底値統計（全主要サイクル）」を追加。
・2011 / 2013 / 2017 / 2021 / 現在について「最大下落率」と「ATH→底までの日数」を常時並列表示。
・過去4サイクル平均（最大下落率 / ATH→底日数）を自動計算。
・現在サイクルは「暫定」と明示。安値更新時は自動更新。


[v3.4 変更点]
・Binance日足 kline の Low（row[3]）をClose（row[4]）と別に取得し、localStorageへ保存。
・現行サイクルの最安Low、日付、ATH終値比、ATH後日数、60,000ドル一時到達の有無を上部に表示。
・過去統計と既存のグラフは日足終値ベースのまま変更しない。
・底値統計の下に2017・2021・現在サイクルのLow比較を独立表示。2011/2013はLowがないため含めない。
・当日の日足は確定終値ではないことを明記し、60,000ドル条件は直近価格と一時到達を分離。
・旧v3.3の保存データは読み込めるが、Lowがない場合は「未取得」と表示し、更新で取り直す。
・Service Workerのキャッシュ名をv3.4に更新。
・注意：55,500ドルなどの具体的な安値は使用データソース（Binance BTCUSDT）の実測値次第。異なる取引所の安値を自動採用しない。
・Service Workerは試験版v3系キャッシュだけを整理し、他アプリのキャッシュは削除しない。
