BTCサイクル比較 v3.5 ― Low底値基準・底値前後軸の統一
2026-11-22

【修正の目的】
v3.4は日中最安値（Low）を表示するものの、底値前後の0日・最大下落率・比較表は終値のままだった。
v3.5では2017年以降の主要サイクルに日足Lowを底値判定として採用し、関連数値と0日を連動させた。

【変更】
・2011／2013サイクル：終値の最安値を底値にする。初期データには同一基準のLow履歴がない。
・2017／2021／現在サイクル：Binance BTCUSDTの日足Lowの最安値を底値にする。
・ATHの分母：従来通り日足終値の最高値。Low比との混合であることを明示。
・「ATH→暫定底」表示、底値統計、比較表、最大下落率、底値日、ATH→底日数を上記基準に統一。
・「底値前後」0日を採用底値日へ移動。ATH→底値／ATH→次ATHの底値マーカーにも適用。
・折れ線グラフは従来通り終値で描く。白抜き丸は採用した底値、Lowは当日終値からLowへの縦点線を併記する。
・終値基準の底値も補足表示し、Lowとの違いを確認できる。
・過去4サイクル平均は初期の終値・近年のLowが混じるため参考平均と明記。
・古い保存データにLowが欠ける場合は終値にフォールバックし「Low未取得」を明示する。更新ボタンで取り直す。
・Service Workerキャッシュ名をv3.5に更新。

【既存機能の維持】
・2010年7月からの過去データ、主要ATHの定義、2013統合、サイクルON/OFF、全表示。
・ATH→現在、ATH→底値、底値前後、ATH→次ATHの4モード。
・100/200/365/500日、ATH→次ATHの1000/1500日等の範囲選択。
・PC／iPhone／Androidの画面、保存機能、60,000ドル直近価格／一時到達の別判定。

【データソース】
・2010-07-18〜2017-08-16：CoinGecko由来BTC/USD日足終値（公開GitHubミラー）。
・2017-08-17以降：Binance BTCUSDTスポット日足の終値（close）と最安値（low）。
・異なる取引所間では価格・安値が異なる場合がある。日付はUTC。
・進行中の足は未確定。現在サイクルの最終底値は未確定。

[v3.6 購入履歴・評価損益の追加]
- 購入日、円/BTC単価、ドル/BTC単価（任意）、数量BTC、円手数料（任意）を登録。
- CSV / Excelのタブ区切りをまとめて貼り付け。GMO等のヘッダー付き履歴の主要列にも対応。
- 履歴はこの端末のlocalStorage保存。GitHub Pages／外部APIに取引内容は送信しない。別端末とは非同期。
- 円評価：公開GMO BTC_JPY tickerのlastを優先、失敗時はbitbank。手動円価格も可。
- ドル評価：Binance BTCUSDT ticker、失敗時はサイクル比較の日足価格（時刻表示付き）。
- 円損益＝保有数量×現在円価格－（円単価×数量＋入力円手数料）
- ドル損益＝保有数量×現在ドル価格－（ドル単価×数量）。ドル単価が一部未入力ならドル損益は非表示。
- 入力ミス修正・1件削除・CSVバックアップ・置き換え・一括削除を提供。
- BTC購入履歴は未売却の数量のみを入れること。売却履歴の自動相殺には非対応。
- 比較チャート／底値ロジック／ON OFF／期間切替はv3.5から変更していない。
- 日本円とドルの参照先は異なる取引所なので相場換算に差がある。税金・手数料・スプレッドは別途確認。
- 正式版を直接上書きせず、v3-testの4ファイルだけを試験版へ反映する。

[v3.7 変更点]
・購入履歴は1件ごとに折り畳み。通常は「日時／BTC数量／入力取得額」だけ表示。タップで単価・手数料・編集・削除を表示。
・登録済み全購入分の円建て合計評価損益と評価損益率を、購入履歴セクション最上部に大きく表示する。
・現行の合計計算ロジック（取得額＝円単価×BTC数量＋入力手数料、時価評価額＝数量×BTC/JPY）を維持。
・市場価格が未取得なら推定値は出さず、価格更新または手動円価格入力を案内。
・購入履歴の保存キー「btc_cycle_compare_v3_6_purchase_history」は変更しない。既存の履歴は保持。
・売却履歴未対応・税金未反映。ここでいう合計損益は登録した未売却購入分のみの概算。
・通常のATH比較・底値比較・サイクルON/OFF・円/ドル評価・CSV保存の既存機能は変更しない。
・データは端末のlocalStorage内に保存。個人の購入履歴を外部送信しない。

[v3.8 変更点]
・平均取得単価（円/BTC）、平均取得単価（ドル/BTC）を購入損益カードの上段へ個別表示。
・ドル約定単価が未入力の場合はローカル保存済みBTC/USDT（UTC）日足終値で「参考」ドル取得単価・参考損益を表示。
・明示入力されたドル約定単価を最優先。推計値は購入履歴レコードに保存しない。
・日足終値と実際の約定時レートは異なる。全件の参考価格が揃わない場合はドル損益を未算出のままにする。
・2017-08-17以降の日足履歴に対応。チャート側の「更新」ボタンを押すと参考ドル平均も更新される。
・円購入金額・円損益・購入履歴の登録内容と保存キー、CSV形式、サイクル比較グラフは変更しない。
