BTCサイクル比較 v1.8

【目的】
BTCの過去サイクルと現在サイクルを比較し、現在がATH後のどの位置にあるか、過去サイクルの底から天井までの上昇力がどの程度だったか、購入検討時期の目安がどのあたりかを確認するためのHTML単体アプリ。

【ZIP構成】
・index.html
・manifest.webmanifest
・sw.js
・README_iPhone_API.txt

【使い方】
1. index.html をブラウザで開く。
2. 「最新データ取得」を押す。
3. データ取得後、以下の4モードを切り替えて確認する。
   ・同日数比較
   ・ATH→次ATH
   ・底→天井
   ・全期間

【表示モード】
1. 同日数比較
現在サイクルのATH後日数に合わせ、過去サイクルも同じ日数で切って比較する。
例：現在がATH後236日なら、2017天井後も前回天井後も236日まで表示する。

2. ATH→次ATH
天井から次の大きな天井、または現在までを実日数で比較する。
サイクルの長さの違いも確認するため、X軸は実日数のまま表示する。

3. 底→天井
弱気相場の底を1倍として、次の大きな天井までの倍率を比較する。
Y軸は倍率の対数表示。巨大な2018サイクルで近年サイクルが潰れないようにしている。
現在ATH後の底は未確定なので、取得済みデータ内のATH後安値を暫定底として扱う。

4. 全期間
Binance BTCUSDTの日足終値を全期間表示する。

【v1.8の主な変更】
・補助情報から「2024年半減期からの日数」と重複する「現在ATH」を削除。
・補助情報に「購入検討目安（過去底日数型）」を追加。
・購入検討目安は、過去2サイクルのATHから底打ちまでの日数を現在ATHに当てはめ、前後約3か月の余裕を持たせて年月レンジ表示する。
・補助情報に「購入条件：60,000ドル以下中心」を表示。
・v1.7以前の保存データも読み込み可能。

【データ取得元】
Binance Spot API
BTCUSDT daily klines
https://api.binance.com/api/v3/klines

【APIキー】
APIキーは不要。
HTML内にもAPIキーは保存しない。

【保存仕様】
取得した価格データと選択モードは、使用端末のlocalStorageに保存する。
保存先はこの端末内のみ。

【GitHub Pagesへの上書き】
既存リポジトリに以下4ファイルをそのまま上書きする。
・index.html
・manifest.webmanifest
・sw.js
・README_iPhone_API.txt

【iPhone Safariで使う場合】
1. GitHub PagesのURLをSafariで開く。
2. 共有ボタンを押す。
3. 「ホーム画面に追加」を選ぶ。
4. ホーム画面のアイコンから起動する。

【注意】
・数値はBinance BTCUSDTの日足終値ベース。
・一般的なBTC ATH表記とは、取引所、日足基準、終値/高値の違いにより差が出る。
・Binanceのデータ開始前である2013年サイクルは未搭載。
・現在ATH後の底は未確定。底→天井モードの現在分は暫定表示。
・購入検討目安は売買推奨ではなく、過去サイクルから見た時期の目安。
・購入判断では、60,000ドル以下などの価格条件、資金量、税金、マクロ環境、心理的負担を別途確認する。

【通信失敗時】
・家庭/会社ネットワークでBinance APIが遮断されている可能性がある。
・保存済みデータがある場合は「保存データ表示」を押す。
・GitHub Pagesで古い画面が残る場合は、Safariの再読み込み、またはホーム画面アイコンの作り直しを行う。
