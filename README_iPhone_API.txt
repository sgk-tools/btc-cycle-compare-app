BTCサイクル比較 v1.6

【目的】
BTCの過去サイクルと現在サイクルを比較し、現在がATH後のどの位置にあるか、また過去サイクルの底から天井までの上昇力がどの程度だったかを確認するためのHTML単体アプリ。

【ZIP構成】
・index.html
・manifest.webmanifest
・sw.js
・README_iPhone_API.txt

【使い方】
1. index.html をブラウザで開く。
2. 「最新データ取得」を押す。
3. データ取得後、以下の4モードを切り替えて確認する。
   ・同日数比較
   ・ATH→次ATH
   ・底→天井
   ・全期間

【表示モード】
1. 同日数比較
現在サイクルのATH後日数に合わせ、過去サイクルも同じ日数で切って比較する。
例：現在がATH後236日なら、2017天井後も前回天井後も236日まで表示する。

2. ATH→次ATH
天井から次の大きな天井、または現在までを実日数で比較する。
サイクルの長さの違いも確認するため、X軸は実日数のまま表示する。

3. 底→天井
弱気相場の底を0%として、次の大きな天井までの上昇率を比較する。
2018底→前回天井、2022底→現在天井、現在ATH後暫定底→現在を表示する。
現在ATH後の底は未確定なので、取得済みデータ内のATH後安値を暫定底として扱う。

4. 全期間
Binance BTCUSDTの日足終値を全期間表示する。

【v1.6の主な変更】
・上部カードから「2024年半減期からの日数」を外し、補助情報欄へ移動。
・メイン情報をBTC価格、現在ATHからの下落率、現在ATH後の日数、データ基準に整理。
・底→天井モードを追加。
・v1.3以前の保存データも読み込み可能。

【データ取得元】
Binance Spot API
BTCUSDT daily klines
https://api.binance.com/api/v3/klines

【APIキー】
APIキーは不要。
HTML内にもAPIキーは保存しない。

【保存仕様】
取得した価格データと選択モードは、使用端末のlocalStorageに保存する。
保存先はこの端末内のみ。

【GitHub Pagesへの上書き】
既存リポジトリに以下4ファイルをそのまま上書きする。
・index.html
・manifest.webmanifest
・sw.js
・README_iPhone_API.txt

【iPhone Safariで使う場合】
1. GitHub PagesのURLをSafariで開く。
2. 共有ボタンを押す。
3. 「ホーム画面に追加」を選ぶ。
4. ホーム画面のアイコンから起動する。

【注意】
・数値はBinance BTCUSDTの日足終値ベース。
・一般的なBTC ATH表記とは、取引所、日足基準、終値/高値の違いにより差が出る。
・Binanceのデータ開始前である2013年サイクルは未搭載。
・現在ATH後の底は未確定。底→天井モードの現在分は暫定表示。
・このアプリはサイクル位置確認用。売買判断そのものではない。
・購入判断では、価格条件、資金量、税金、マクロ環境、心理的負担を別途確認する。

【通信失敗時】
・家庭/会社ネットワークでBinance APIが遮断されている可能性がある。
・保存済みデータがある場合は「保存データ表示」を押す。
・GitHub Pagesで古い画面が残る場合は、Safariの再読み込み、またはホーム画面アイコンの作り直しを行う。

【v1.6修正】
・チャートY軸のプラス表示が欠けてマイナスに見える問題を修正。
・Y軸の左余白を拡大。

【v1.6変更点】
・上部カードの「データ基準」を廃止し、「前回ATH後 同日数下落率」に変更。
・補助情報に「次回半減期（推定）」を追加。
・補助情報に「次回ATH候補（2020型／2024型／平均）」を追加。
・次回半減期は2024年半減期から210,000ブロック×10分で機械計算した概算。実際の日付はブロック生成速度で前後します。
・次回ATH候補は過去の半減期→ATH日数を単純加算した位置確認用であり、価格予測・売買判断ではありません。
