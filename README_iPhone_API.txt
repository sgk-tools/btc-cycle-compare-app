BTC現在地 v2.1 compare

目的
- BTCの現在位置と、過去サイクルとの比較を一画面で確認するアプリ。
- 売買判断ではなく、価格・ATH後日数・ATH比・60,000ドル条件・過去サイクル比較を確認する。

主な変更
- v2.0 minimalで削り過ぎた比較情報を、過去比較カードとして復活。
- ATHモード時に以下を表示。
  - 現在のATH比下落率
  - 2017型の同日数下落率
  - 前回型の同日数下落率
  - 現在が過去より浅いか深いか
  - 選択期間内の最大下落率
  - 次ATHまでの過去平均日数との比較
- 操作は「更新」と「日足/週足/月足/年足/ATH」の切替に集約。
- ATH比較だけ、500日/1000日/1500日/全期間を選択可能。
- 日足/週足/月足/年足は日足終値から作成した終値ベースの折れ線。ローソク足ではない。
- 価格チャートは長期確認のため対数表示。

データ
- Binance Spot API BTCUSDT daily klines
- APIキー不要
- localStorageに保存

注意
- PWAキャッシュが残る場合は、ブラウザ更新、キャッシュ削除、またはホーム画面アプリを削除して再追加する。
- このアプリは位置確認用。買い・売り判断は別途、価格条件、マクロ環境、資金量、税金、心理的負担を確認する。
