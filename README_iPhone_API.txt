BTC現在地 v2.0 minimal

目的
- BTCの現在位置を一画面で見るための最小構成アプリ。
- 売買判断ではなく、価格・ATH後日数・ATH比・60,000ドル条件・サイクル比較を確認する。

主な変更
- 補助情報、表、長い説明を削除。
- 操作は「更新」と「日足/週足/月足/年足/ATH」の切替に集約。
- ATH比較だけ、500日/1000日/1500日/全期間を選択可能。
- 日足/週足/月足/年足は日足終値から作成した終値ベースの折れ線。ローソク足ではない。
- 価格チャートは長期確認のため対数表示。

データ
- Binance Spot API BTCUSDT daily klines
- APIキー不要
- localStorageに保存

GitHub Pages反映
1. index.html
2. manifest.webmanifest
3. sw.js
4. README_iPhone_API.txt
をGitHubへ上書きアップロードする。

注意
- PWAキャッシュが残る場合は、ブラウザ更新、キャッシュ削除、またはホーム画面アプリを削除して再追加する。
- このアプリは位置確認用。買い・売り判断は別途、価格条件、マクロ環境、資金量、税金、心理的負担を確認する。
