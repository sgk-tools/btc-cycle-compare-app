BTCサイクル比較 v2.3 loading

目的
- BTCの過去サイクルと現在サイクルを比較する専用アプリ。
- 日足/週足/月足/年足の通常チャートは削除。
- 売買判断ではなく、ATH後日数、ATH比下落率、ATHから底値までの日数、底値前後の形を確認する。

主な変更
- 通常チャート切替を削除。
- 比較モードを4つに整理。
  1. ATH→現在
  2. ATH→底値
  3. 底値前後
  4. ATH→次ATH
- ATH→底値までの日数と最大下落率を表示。
- 底値前後チャートを追加。
  - 底値日を0日として、±180日 / ±365日 / ±540日を選択可能。
- 現在サイクルの底値は未確定のため「暫定底」と明記。
- ATH→次ATHは500日 / 1000日 / 1500日 / 全期間を選択可能。
- 底値位置はグラフ上のマーカーで表示。
- 更新ボタン押下中は「取得中」と表示し、二重押しを防止。

データ
- Binance Spot API BTCUSDT daily klines
- APIキー不要
- localStorageに保存

GitHub Pages反映
1. index.html
2. manifest.webmanifest
3. sw.js
4. README_iPhone_API.txt
をGitHubへ上書きアップロードする。

注意
- PWAキャッシュが残る場合は、ブラウザ更新、キャッシュ削除、またはホーム画面アプリを削除して再追加する。
- 現在サイクルの底値は確定値ではない。今後さらに安値を更新すれば、暫定底と底値前後チャートの0日位置は変わる。
- このアプリは位置確認用。買い・売り判断は別途、価格条件、マクロ環境、資金量、税金、心理的負担を確認する。
